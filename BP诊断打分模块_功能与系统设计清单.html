BioFin智投引擎 · 核心功能模块

BP全自动诊断与打分系统 · 平台功能与系统设计清单

面向融资项目方上传的商业计划书（BP），构建集「基础框架评估 + 管线深度诊断 + 资本逻辑校验 + 风险点智能高亮」于一体的AI全自动诊断与打分引擎，输出结构化诊断报告与量化评分，为投行立项、尽调、融资方案设计提供智能决策支撑。

文档版本：V1.0 编制部门：产品与技术部 开发周期：约 12 周（3个月） 总预算：约 85–110 万元 优先级：P1 核心 / P2 重要 / P3 增强 / P4 远期

1系统定位与总体架构 System Positioning & Architecture

系统定位：作为BioFin智投引擎的「第一入口」与「获客抓手」，承接BP上传→AI诊断→打分→报告输出→增值服务导流的完整转化链路。对内服务投行承揽/承做/风控，对外服务药企创始人/融资方。

架构层级核心组件说明
接入层BP上传端口（PDF/Word/PPT/文字粘贴/线上问卷）多格式解析、OCR识别、版式还原、敏感信息脱敏
解析层文档解析引擎 + 结构化抽取器章节识别、表格抽取、图表OCR、关键字段自动定位
诊断层四大诊断引擎（框架/管线/资本/风险）规则引擎 + 垂直大模型 + 知识库RAG检索增强
评分层多维度加权评分模型 + 评级输出百分制总分 + 四维分项分 + 等级（A/B/C/D）
输出层诊断报告生成器 + 可视化看板PDF/在线报告、雷达图、风险热力图、改进建议清单
数据层行业知识库 / 18A案例库 / 机构偏好库 / 估值参数库向量化存储 + 结构化数据库 + 持续更新机制
设计原则：① 模块化解耦，四大诊断引擎可独立迭代；② 规则引擎兜底 + 大模型增强，确保专业准确率与可解释性；③ 全链路留痕，支持人工复核与合规审计；④ 输出标准化，为后续融资方案引擎、机构匹配库提供结构化数据底座。
