# BioFin 智投引擎 · BP 全自动诊断打分系统

> 面向生物医药（Biotech）领域的商业计划书（BP）智能诊断与评分平台

## 📌 项目简介

BioFin 智投引擎是一个专为生物医药行业设计的 **BP（商业计划书）全自动诊断打分系统**。系统通过多模块协同工作，对生物医药企业的商业计划书进行结构化解析、多维度评估与智能评分，帮助投资机构、孵化器及企业自身快速评估项目质量与投资价值。

## 🏗️ 系统架构

系统采用 **A/B/C/D/E/F/G** 七大评估维度，共 27 个功能模块：

### 核心处理引擎（模块 1-7）
| 模块 | 功能 |
|------|------|
| 模块1 | 文档解析与 OCR 引擎 |
| 模块2 | 结构化信息抽取器 |
| 模块3 | 行业知识库搭建 |
| 模块4 | 18A 案例库搭建 |
| 模块5 | 估值参数库搭建 |
| 模块6 | 垂直大模型微调 |
| 模块7 | RAG 检索增强模块 |

### A 维度 · 商业计划书完整性（模块 8-10）
| 模块 | 功能 |
|------|------|
| 模块8 | A1 结构完整性扫描 |
| 模块9 | A2 商业逻辑闭环校验 |
| 模块10 | A3 叙事流畅度评估 |

### B 维度 · 技术与产品评估（模块 11-13）
| 模块 | 功能 |
|------|------|
| 模块11 | B1 临床数据解析与分期校验 |
| 模块12 | B2 技术差异化与竞争格局 |
| 模块13 | B3 专利壁垒与 IP 评估 |

### C 维度 · 财务与融资评估（模块 14-16）
| 模块 | 功能 |
|------|------|
| 模块14 | C1 估值合理性校验 |
| 模块15 | C2 融资金额与稀释测算 |
| 模块16 | C3 资金使用计划审查 |

### D 维度 · 风险识别（模块 17-19）
| 模块 | 功能 |
|------|------|
| 模块17 | D1 合规风险筛查 |
| 模块18 | D2 现金流与资金链压力 |
| 模块19 | D3 研发失败率与临床风险 |

### E 维度 · 评分与输出（模块 20-22）
| 模块 | 功能 |
|------|------|
| 模块20 | E3 评分模型与权重体系 |
| 模块21 | E4 诊断报告生成器 |
| 模块22 | E5 可视化诊断看板 |

### F 维度 · 平台运营（模块 23-26）
| 模块 | 功能 |
|------|------|
| 模块23 | F1 用户与权限管理 |
| 模块24 | F2 计费与套餐管理 |
| 模块25 | F3 数据安全与合规审计 |
| 模块26 | F4 运营后台与数据看板 |

### G 维度 · 远期增强（模块 27）
| 模块 | 功能 |
|------|------|
| 模块27 | G1-G4 远期增强模块 |
